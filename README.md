# Оперативный штаб 0.4

Мобильная браузерная учебная стратегия на вымышленной схеме района.

## Запуск
Загрузите все файлы из этой папки в корень GitHub-репозитория. В Settings → Pages выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`.

## Возможности
- Русский интерфейс и адаптация под смартфоны.
- Две учебные миссии: паводок и энергосбой.
- Условные красная и синяя игровые стороны.
- Авторские символы групп и объектов (не официальные тактические обозначения).
- Перетаскивание карты, масштабирование кнопками и жестом двумя пальцами.
- Учебные действия: перемещение к объекту, поддержка, доставка ресурсов, проверка информации.
- Ходы, показатели, журнал и экспорт JSON.

## Примечание
Стороны, карта, обозначения и сценарии вымышлены. Игра не содержит реальных координат, официальных тактических знаков или моделей боевого применения.
