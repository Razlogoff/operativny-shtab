# Оперативный штаб 0.5

Мобильная браузерная пошаговая стратегия на вымышленной карте.

## Запуск
Откройте `index.html` или опубликуйте содержимое папки через GitHub Pages.

## Управление
- Выберите красную группу в списке или на карте.
- Нажмите «Переместить», затем выберите соседний свободный сектор.
- «Поддержать сектор» повышает координацию.
- «Восстановить ресурс» пополняет ресурс выбранной группы.
- В конце хода соперник делает абстрактный ход, затем начисляются очки за контроль контрольных пунктов.
- Масштаб: кнопки +/- или жест двумя пальцами; панорамирование: перетаскивание карты.
