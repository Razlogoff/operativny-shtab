# Оперативный штаб — браузерный прототип 0.2

Русскоязычная адаптивная игра для смартфонов и компьютеров. Не требует библиотек, сервера или сборки: откройте `index.html` в современном браузере.

## Запуск
- На компьютере: открыть `index.html`.
- На телефоне: разместить папку на любом статическом хостинге (например, GitHub Pages или Codeberg Pages) и открыть ссылку в браузере. После первого открытия онлайн игра кешируется и может запускаться без сети. Для установки на главный экран используйте меню браузера «Добавить на экран домой».

## Что работает
- Вертикальная мобильная компоновка и сенсорная карта 5×5.
- Русский интерфейс.
- Выбор секторов и назначение четырёх рабочих групп.
- Задачи, ходы, игровые показатели и журнал решений.
- Учебный и игровой режимы (переключение через справку).
- Сохранение прогресса в localStorage и экспорт журнала в JSON.

## Ограничения
Это MVP, а не законченная многопользовательская игра. Пока нет аккаунтов, синхронизации между устройствами, редактора сценариев и сетевой игры. Модель полностью вымышленная и абстрактная; показатели предназначены для игрового баланса, не для реального планирования.
