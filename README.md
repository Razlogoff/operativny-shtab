# Оперативный штаб v0.3

Мобильная пошаговая браузерная стратегия на вымышленной карте региона.

## Файлы
Загрузите все файлы из этой папки в корень репозитория GitHub Pages: `index.html`, `style.css`, `app.js`, `manifest.webmanifest`, `sw.js`.

## Возможности
- адаптивная карта 7×7 с условными обозначениями местности;
- пять абстрактных подразделений: штабная, инженерная, обеспечивающая, медицинская и связная группы;
- выбор сектора и подразделения;
- пошаговые приказы: перемещение в соседний сектор, поддержка инфраструктуры, поддержание порядка;
- игровые показатели снабжения, координации и стабильности;
- задачи, события, журнал и экспорт JSON;
- сохранение прогресса на устройстве.

## Публикация
Замените файлы в корне существующего репозитория `Razlogoff/operativny-shtab`. В GitHub Pages оставьте `main` и `/ (root)`. После коммита обновите страницу сайта. Если старая версия останется в кеше, закройте вкладку и откройте сайт заново.

Все сценарии, сектора и обозначения вымышлены. Механики предназначены для игры о координации, ресурсах и поддержке инфраструктуры, а не для реального планирования военных действий.
